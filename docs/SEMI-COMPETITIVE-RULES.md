# Semi-competitive starting rules

Choose **Semi-competitive · 4 pilots** in the host form or lobby quick setup.

- Four seats, two automatically balanced human teams, Team Death Match, first to three round wins. A host playing alone waits for opponents; NPC fill is disabled.
- Competitive view is enabled: clients use equal world coverage. Eliminated team members can follow living allies only; with no living allies, the camera stays where they died. Casual matches retain their existing camera options.
- Random pickups, permanent pickup accumulation, and optional arena effects are disabled. The explicit nine-map pool is Core Arena, Riftline, Prism Array, Twin Suns, Dead Freight, Longwave Array, Broken Orbit, Switchyard, and Relay Zero. Solar Tide, Wormhole, and Solar Crucible are excluded, so currents, gravity, lethal horizons, flares, and surface burns cannot enter the preset's rotation. Normal seeded drafting remains part of the match; this is not a fixed-loadout mode.
- Only the host can pause or resume a running match. Pausing freezes simulation and match deadlines, clears held inputs on both edges, and keeps network refreshes running. There is no pause quota or automatic timeout. Agree on pause use before organized games.
- Leaving mid-heat eliminates the player. If they took hull damage from an opponent in the previous five seconds, that opponent is credited with the kill, and the kill feed shows "left, kill to" the opponent, so disconnecting cannot deny an earned elimination. This applies in every mode, not only this preset.
- Applying a preset clears readiness and restores automatic team assignment. It never removes connected humans. The host may edit advanced settings afterward; inspect those settings before readying up. The MAPS tab shows the selected pool and each map's active mechanics; changing maps clears readiness. Maps and hazard settings are frozen for the match and retained on a fresh rematch. Other presets preserve an explicitly selected competitive-view setting.

Duel, Skirmish, and Team objective restore all twelve maps with optional events off and intrinsic map mechanics active. Chaos restores all twelve maps with signature events enabled. Switching presets resets the pool and all event options. Solar Crucible's flare damage remains adjustable with optional effects Off; its random flare intervals, fixed contact burns, and gravity are unaffected by that control.

This is a reproducible starting configuration for casual competition, not an anti-cheat guarantee. Camera restrictions apply in the normal client; player snapshots are not filtered to enforce observer confidentiality against modified clients. Internet play and tournament administration still need their own latency, integrity, and conduct checks.
