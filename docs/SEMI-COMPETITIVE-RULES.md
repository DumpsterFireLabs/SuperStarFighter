# Semi-competitive starting rules

Choose **Semi-competitive · 4 pilots** in the host form or lobby quick setup.

- Four seats, two automatically balanced human teams, Team Death Match, first to three round wins. A host playing alone waits for opponents; NPC fill is disabled.
- Competitive view is enabled: clients use equal world coverage. Eliminated team members can follow living allies only; with no living allies, the camera stays where they died. Casual matches retain their existing camera options.
- Random pickups, permanent pickup accumulation, and arena effects are disabled. Normal seeded drafting remains part of the match; this is not a fixed-loadout mode.
- Only the host can pause or resume a running match. Pausing freezes simulation and match deadlines, clears held inputs on both edges, and keeps network refreshes running. There is no pause quota or automatic timeout. Agree on pause use before organized games.
- Applying a preset clears readiness and restores automatic team assignment. It never removes connected humans. The host may edit advanced settings afterward; inspect those settings before readying up. Other presets preserve an explicitly selected competitive-view setting.

This is a reproducible starting configuration for casual competition, not an anti-cheat guarantee. Camera restrictions apply in the normal client; player snapshots are not filtered to enforce observer confidentiality against modified clients. Internet play and tournament administration still need their own latency, integrity, and conduct checks.
